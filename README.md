AGCR-LRD is the official implementation of the proposed hyperspectral anomaly detection algorithm.

The two new hyperspectral datasets used in this work (Hohai_camouflage.mat and Hohai_coin.mat) are not stored in this repository due to their large file sizes.
You can download them from the following release link:

👉 https://github.com/skipper12138/AGCR-LRD/releases/edit/datasets

After downloading, place the .mat files in the appropriate data folder to run the code
